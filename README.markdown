# 4917 Longest String

## Overview

This project finds the **longest possible output string** that can be generated by programs running on the custom 4917 microprocessor. See `PROJECT_CONTEXT.md` for complete technical details.

## Quick Start

Build and run the Haskell implementation:

```bash
cd haskell-impl
stack build
stack run 4917-cli -- --help
```

## Available Commands

- `stack run 4917-cli -- search --length 3` - Find longest output for length-3 programs
- `stack run 4917-cli -- cache-demo --fresh` - Demonstrate caching performance
- `stack run 4917-cli -- benchmark` - Performance benchmarking across lengths
- `stack run 4917-cli -- test` - Run test suite

## Goal

Find the program of a given length (3-8 instructions) that produces the longest possible output string when executed on the 4917 microprocessor.

## Features

- **Advanced Caching**: Persistent memoization with pattern analysis
- **Optimization Strategies**: HALT detection, loop analysis, dead code elimination
- **Performance Monitoring**: Detailed execution tracing and benchmarking
- **Correctness**: Comprehensive test suite ensuring accurate results

## Dependencies

- **Haskell Stack** (for building and running)
- **GHC** 8.10+ (managed by Stack)
