# Initial C benchmark sample

Informational single-run baseline captured 2026-11-15 from repository
revision `a00d3f4`. Build: CMake 4.4.5 `Release`, AppleClang 17.0.0.17000013,
Darwin 24.6.0, ARM64 (`T6041`). Invoke with
`cmake --preset benchmarks && cmake --build --preset benchmarks &&
./build/make-benchmarks/4917-bench`. Each line below includes its fixed
repetition/candidate count. Run multiple repetitions on an otherwise idle
machine before drawing performance conclusions; this sample is not a gate.

| Workload | Median throughput (min–max) | Work per sample |
| --- | ---: | ---: |
| short straight line | 135.9 M instructions/s (120.5–144.7) | 3,000,000 instructions, 1,000,000 runs |
| arithmetic heavy | 159.6 M instructions/s (152.5–164.9) | 64,000,000 instructions, 500,000 runs |
| output heavy | 172.2 M instructions/s (168.2–181.1) | 2,000,000 instructions, 500,000 runs |
| branch loop | 168.1 M instructions/s (167.6–175.9) | 64,000,000 instructions, 250,000 runs |
| self modifying | 181.1 M instructions/s (170.6–185.2) | 32,000,000 instructions, 500,000 runs |
| output cycle detection | 78.5 M logical steps/s (76.7–81.3) | 500,000 steps, 250,000 runs |
| exact length-two search | 16.0 M candidates/s (16.0–17.1) | 256 candidates |

Execution benchmarks include initialization and bounded running, exclude
process startup and formatting, and use a result sink. Cycle detection includes
visited-state allocation and comparison. Search counts actual candidates and
reports the 242 terminating candidates; 14 were unresolved at the 128-step
fixture bound. Each workload was measured five times, with minimum, median,
and maximum throughput emitted by the benchmark's NDJSON mode. These timings
are informational and are not a performance gate.
