# Initial C benchmark sample

Informational single-run baseline captured 2026-11-15 from repository base
revision `13484d8`. Build: CMake 4.4.5 `Release`, AppleClang 17.0.0.17000013,
Darwin 24.6.0, ARM64 (`T6041`). Invoke with
`cmake --preset benchmarks && cmake --build --preset benchmarks &&
./build/make-benchmarks/4917-bench`. Each line below includes its fixed
repetition/candidate count. Run multiple repetitions on an otherwise idle
machine before drawing performance conclusions; this sample is not a gate.

| Workload | Throughput | Work |
| --- | ---: | ---: |
| short straight line | 138.4 M instructions/s | 3,000,000 instructions, 1,000,000 runs |
| arithmetic heavy | 150.3 M instructions/s | 64,000,000 instructions, 500,000 runs |
| output heavy | 176.4 M instructions/s | 2,000,000 instructions, 500,000 runs |
| branch loop | 167.0 M instructions/s | 64,000,000 instructions, 250,000 runs |
| self modifying | 168.2 M instructions/s | 32,000,000 instructions, 500,000 runs |
| output cycle detection | 71.5 M logical steps/s | 500,000 steps, 250,000 runs |
| exact length-two search | 12.8 M candidates/s | 256 candidates |

Execution benchmarks include initialization and bounded running, exclude
process startup and formatting, and use a result sink. Cycle detection includes
visited-state allocation and comparison. Search counts actual candidates and
reports the 242 terminating candidates; 14 were unresolved at the 128-step
fixture bound. Timing precision is intentionally not treated as comparative
evidence until repeated samples and spread are collected.
